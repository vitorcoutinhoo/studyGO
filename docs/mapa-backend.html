Levantamento técnico · studyGO / plantao-app

O que existe hoje na API de plantões

Backend em Go que administra escala, colaboradores, pagamento e comunicação de um serviço de plantões — arquitetura, endpoints, módulos de domínio e o que está rodando por trás, direto do código.

18 grupos de rotas 10 domínios 13 tabelas 2 workers em background 1 integração externa
Go · Gin Uber Fx · injeção de dependência PostgreSQL 16 · pgx/v5 JWT · RS256 Docker Compose

Stack & execução

Router gin, todo o grafo de dependências montado com go.uber.org/fx — cada camada (config, postgres, domínio, api, segurança, workers) é um fx.Module próprio registrado em internal/fx/modules.go. Persistência via pgxpool direto sobre SQL, sem ORM. Autenticação com par de chaves RSA (JWT_PRIVATE_KEY_PATH / JWT_PUBLIC_KEY_PATH).

Dois caminhos de execução convivem: docker compose up --build sobe API + Postgres juntos; ou só o Postgres em container (docker compose up postgres -d) com a API rodando local via go run ./cmd/api — mais rápido para iterar, já que o .env já aponta DB_URL para localhost:5432.

▲ Porta do servidor não é fixa no compose. A aplicação lê SERVER_PORT do ambiente (hoje 8090 no .env local), então rodar via Docker exige sobrescrever essa variável no environment: do serviço app para casar com o mapeamento de porta do docker-compose.yaml — senão o container aceita a conexão TCP mas nada responde do lado do servidor.

Workers em background

internal/worker · registrados como fx.Lifecycle hooks
PlantaoStatusWorker Ativo

Roda a cada 5 minutos, chama IniciarPlantoesAgendados para promover plantões com horário de início já alcançado de agendado para em andamento. Executa uma vez no start e depois no intervalo, com context.CancelFunc para desligamento limpo.

FeriadoSyncWorker Registrado, não iniciado

Sincronizaria feriados do ano corrente com a API Invertexto a cada 24h, só disparando a chamada de fato quando o ano ainda não tiver sido sincronizado (lastSyncedYear em memória). Hoje o fx.Invoke(worker.RegisterFeriadoSyncWorker) está comentado em cmd/api/main.go — os 18 feriados de 2026 já foram importados manualmente e não há necessidade de rechamar a API a cada restart. Reativar descomentando essa linha, tipicamente na virada do ano.

O servidor lia SERVER_PORT=8090 do .env mesmo dentro do container, enquanto o docker-compose.yaml só mapeava 8080 — conexões TCP eram aceitas mas nunca respondidas. Adicionado SERVER_PORT: "8080" ao environment: do serviço app.
